### Fixed
- A failed sync no longer forgets what it owed. A push that errored dropped its pending work, so a deleted quote could disappear locally and stay in the cloud with nothing left to retry the deletion.
- Pulling no longer discards local changes that have not been sent yet.
- Sync failures are reported instead of being swallowed. An unreachable record zone used to be indistinguishable from an empty one, which is how the problem above stayed invisible.
