### Fixed
- iCloud sync works. It never did in a released build: the CloudKit schema had only ever been deployed to the development environment, so every signed copy of KindleWall failed silently against production. Nothing you had was lost — nothing had been reaching the cloud to lose.
- Sync recovers when the record zone goes missing instead of failing forever. The "zone already created" mark lived only on your Mac, so once the server no longer had the zone, the app stopped trying.
