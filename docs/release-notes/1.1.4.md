### New
- **Check for New Highlights.** Your Kindle appends to `My Clippings.txt` as you read, so the copy KindleWall imported last month is not the copy on your device today. Settings → Behavior → Source File now re-reads the file already on record — no walking through the open panel again — and reports what it found: how many new highlights, across how many books, which books gained the most, and which of them are new to your library. Only the new ones are added; favorites and shown state are kept.

### Fixed
- New books were counted wrong. A new highlight in a book you already had was announced as a brand-new book, because the count was measured against the library in memory, which at launch holds only quotes you added by hand.
- The import summary mixed Turkish into the English build and reported how many seconds it took instead of what it found.
- Opening the window no longer shows an import banner. That import runs every time and had nothing to say when nothing had changed.
- Two settings headings were never translated.
